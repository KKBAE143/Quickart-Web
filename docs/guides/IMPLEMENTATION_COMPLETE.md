## 🎨 **Color Reference**

### Primary Red Palette:
```css
/* Main Gradient */
bg-gradient-to-r from-red-600 to-red-700

/* Hover State */
hover:from-red-500 hover:to-red-600

/* Text Colors */
text-red-600   /* Bright - icons, accents */
text-red-700   /* Medium - titles, labels */
text-red-800   /* Dark - emphasis, headings */

/* Focus States */
focus:border-red-600
focus:shadow-lg focus:shadow-red-500/20

/* Borders */
border-red-600      /* Primary */
border-red-200      /* Light hover */
border-red-300      /* Dashed lines */
```

### Standard Patterns:

#### Primary Button:
```jsx
className="bg-gradient-to-r from-red-600 to-red-700 
           hover:from-red-500 hover:to-red-600 
           px-4 py-3 rounded-lg text-white font-semibold 
           shadow-lg hover:shadow-xl 
           transition-all duration-300 hover:scale-105"
```

#### Form Input:
```jsx
className="border-2 border-gray-200 
           focus:border-red-600 
           focus:shadow-lg focus:shadow-red-500/20 
           rounded-lg p-2 outline-none 
           transition-all duration-300"
```

#### Product Card:
```jsx
className="border-2 border-gray-100 
           hover:border-red-200 
           rounded-xl hover:shadow-lg 
           transition-all duration-300 hover:scale-105"
```
