## 💡 Naming Convention:

Use UPPERCASE with underscores:
- `QUICK_REFERENCE_*.md` - For quick reference guides
- `*_GUIDE.md` - For comprehensive guides
- `IMPLEMENTATION_*.md` - For implementation docs
- `*_CHECKLIST.md` - For checklists
- `BEST_PRACTICES_*.md` - For best practices

## 📚 Guide Documentation Template:

When creating a guide, include:
1. **Purpose** - What the guide covers
2. **Prerequisites** - What you need to know
3. **Steps/Sections** - Organized content
4. **Examples** - Practical examples
5. **Tips & Tricks** - Helpful insights
6. **Common Pitfalls** - What to avoid
7. **References** - Related documentation
