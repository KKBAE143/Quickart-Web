## ⚠️ STRICT RULES (Added to `.cursorrules`)

### 🚫 NEVER DO:
- ❌ Create `.md` files in the project root (except main `readme.md`)
- ❌ Put documentation in random folders
- ❌ Use inconsistent naming conventions

### ✅ ALWAYS DO:
- ✅ Place all new documentation in `docs/` folder
- ✅ Use the appropriate subfolder based on doc type
- ✅ Use UPPERCASE naming (e.g., `FEATURE_NAME_GUIDE.md`)
- ✅ Update `docs/README.md` when adding new documentation
- ✅ Check subfolder README for guidelines before creating docs

| If your documentation is about... | Put it in... |

| Design, UI/UX, styling | `docs/ui-ux/` |
| References, guides, checklists | `docs/guides/` |
| Error fixes, debugging | `docs/troubleshooting/` |
