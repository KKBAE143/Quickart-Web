## 🎯 Color Reference Guide

### Button Patterns
```jsx
// Primary Button
className="bg-gradient-to-r from-red-600 to-red-700 hover:from-red-500 hover:to-red-600 px-4 py-3 rounded-lg text-white font-semibold shadow-lg hover:shadow-xl transition-all duration-300 hover:scale-105"

// Secondary/Outline Button  
className="border-2 border-red-600 text-red-700 hover:bg-gradient-to-r hover:from-red-600 hover:to-red-700 hover:text-white px-4 py-3 rounded-lg transition-all duration-300"

// Small Button
className="bg-gradient-to-r from-red-600 to-red-700 hover:from-red-500 hover:to-red-600 px-2 py-1 rounded text-white transition-all duration-300"
```

### Input/Form Patterns
```jsx
// Text Input
className="border-2 border-gray-200 focus:border-red-600 focus:shadow-lg focus:shadow-red-500/20 rounded-lg p-2 outline-none transition-all duration-300"

// Form Label
className="font-semibold text-gray-700"
```

### Link Patterns
```jsx
// Primary Link
className="text-red-600 hover:text-red-700 font-semibold transition-colors"

// Inline Link
className="text-red-600 hover:text-red-700 underline transition-colors"
```

### Card Patterns
```jsx
// Product Card
className="border-2 border-gray-100 hover:border-red-200 rounded-xl hover:shadow-lg transition-all duration-300 hover:scale-105"
```
